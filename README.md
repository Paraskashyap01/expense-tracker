# MERN Expense Tracker

A full-stack Expense Tracker built using the MERN stack.

## Features

- User Authentication (JWT)
- Add Expenses
- Edit Expenses
- Delete Expenses
- Expense Categories
- Dashboard
- MongoDB Database
- Protected Routes

## Tech Stack

- React.js
- Node.js
- Express.js
- MongoDB
- JWT Authentication

## Installation

### Backend

```bash
cd server
npm install
npm start
```

### Frontend

```bash
cd client
npm install
npm run dev
```
